# PaperDesk · 文献手记

一个本地运行的论文笔记工具，支持文献管理、Markdown 与公式、图片、AI 辅助整理，以及会议／期刊和引用数查询。笔记保存在自己的电脑上。

## 开始使用

1. 安装 **Node.js 22 或更高版本**，下载并解压项目。
2. Windows 双击 `start.cmd`；其他系统在项目目录运行 `node server.mjs`。无需 `npm install`。
3. 浏览器打开 [http://127.0.0.1:4174](http://127.0.0.1:4174)，确认左下角显示“自动备份已开启”。

使用时保持服务窗口运行，退出前保存笔记。更新程序后重启服务，再按 **Ctrl+F5** 刷新页面。

## 记录与查找

- **新建笔记**：填写标题、缩写、会议／期刊、日期和标签，写好笔记后点击保存。
- **排版与图片**：支持 `**加粗**`、标题、列表、表格、代码块，以及 `$行内公式$`、`$$独立公式$$`；可上传图片或粘贴截图。
- **星标收藏**：点击阅读状态旁的 ☆ 标记重要论文，点击“★ 只看星标”筛选；再次点击可取消。星标随笔记保存和备份，会议／期刊统一显示在卡片缩写下方。
- **查找文献**：使用搜索框，或按状态、标签和日期筛选；切换“概览表格”集中查看。
- **查询发表信息**：打开论文详情，点击“联网查询”。结果标注来源和查询时间，数据库可能延迟更新。
- **导出**：支持单篇 Markdown、概览 CSV 和完整 JSON 备份。

## AI 辅助整理（可选）

将 `.env.example` 复制为 `.env`，填写配置：

```dotenv
AI_API_KEY=你的密钥
AI_MODEL=模型名称
AI_BASE_URL=服务商的API基础地址
```

服务需支持 Chat Completions 和 JSON mode，地址不附加 `/chat/completions`。配置后重启服务。

在笔记编辑窗口点击“AI 辅助整理”，提供 arXiv 链接或粘贴摘要，生成后核对、勾选字段，再保存。生成会将提供的内容发送给配置的模型服务，可能产生费用。普通笔记功能不需要 API Key。

详细配置见 [AI 使用说明](docs/AI-SETUP.md)，提示词位于 [paper-summary.txt](prompts/paper-summary.txt)。

## 保存与备份

笔记和图片保存在 `data/`。每次成功保存后，自动保留最新 **3 份历史备份**。

换电脑可复制整个 `data/`，或使用“导出完整备份 → 导入备份”。**导入会替换当前文献库**，建议先备份。

请勿上传或分享 `.env` 和 `data/`。独立打开 `Paperdesk.html` 时仅使用浏览器存储，不支持自动落盘和 AI；日常推荐使用 `start.cmd`。
