# 本地存储与恢复

通过 start.cmd 启动并访问 http://127.0.0.1:4174 后，笔记会自动写入本机文件，无需配置 AI。

- data/library.json：当前完整文献库，普通 JSON 数组。
- data/backups/library-时间戳-随机标识.json：每次实际变更前的完整旧版本，包含修改、删除和导入前的内容。
- 只有文件写入成功才提示保存成功；多窗口旧版本写入会被拒绝。
- 重新打开时以电脑文件为准，浏览器仅作为缓存。首次没有电脑文件时，自动迁移当前地址下可读取的浏览器数据。
- 每次成功保存后只保留最新 3 份程序生成的历史备份，多余旧版本自动删除；当前 library.json、images/ 和手动命名的文件不清理。可定期把整个 data 文件夹复制到移动硬盘或你自己的同步盘。

恢复旧版本：在页面点击“导入备份”，选择 data/backups 中需要的 JSON 文件。确认后替换当前文献库；替换之前同样保留一份旧版本。

如果过去双击 Paperdesk.html 使用，或使用另一个浏览器、localhost 地址，必须先在那里导出完整备份，再在本地服务版导入；程序无法直接读取其他浏览器或地址的数据。

直接双击 HTML 不会自动写电脑文件，顶部会标明“仅浏览器保存”。请固定使用 start.cmd 和上述网址。

电脑磁盘损坏或整个项目文件夹被删除仍会影响这两份数据，因此历史备份不能替代其他磁盘上的备份。

data/ 已从 Git 排除，笔记不随源码发布。不要手工修改正在使用的 library.json；先停止服务并复制一份。
