# 启用 AI 文献整理

本次新增的是本地 Node.js 服务 + 模型 API。普通笔记仍可双击 Paperdesk.html 使用；AI 功能需从本地服务打开。暂未部署到公网。

## 配置（只做一次）

1. 将项目根目录的 `.env.example` 复制为 `.env`（注意不要命名为 `.env.txt`）。
2. 用文本编辑器填写三个配置：

```dotenv
AI_API_KEY=填写服务商提供的密钥
AI_MODEL=填写服务商提供的准确模型名称
AI_BASE_URL=https://api.openai.com/v1
```

使用其他兼容服务时，把 AI_BASE_URL 改为该服务文档给出的基础地址，通常包含 `/v1`，不要填写末尾的 `/chat/completions`。模型需要支持 Chat Completions 与 `response_format: {"type":"json_object"}`。本地模型可用 localhost/127.0.0.1 的 HTTP 地址；其他地址要求 HTTPS。

3. 双击 `start.cmd`。保持该窗口运行，在浏览器打开 **http://127.0.0.1:4174**。脚本优先使用 PATH 中的 Node.js，找不到时尝试本机 Codex 已安装的 Node.js；其他电脑需要 Node.js 22 或更高版本。
4. 点击“新建笔记”或编辑已有笔记 → “AI 辅助整理”。配置修改后需要关闭服务窗口并重新启动。

API Key 只由本地服务读取，不放进网页、备份或浏览器存储。不要分享 `.env` 文件。`.gitignore` 已排除它。

## 使用

- 输入 arXiv 的 abs/pdf 链接：服务读取标题、首次发表时间与摘要，交给模型生成候选内容。当前不会读取 PDF 全文。
- 其他论文网址：同时粘贴摘要、正文或个人笔记。当前不会自动抓取其他网站。
- 点击“生成草稿”会将输入、读取到的 arXiv 摘要及文献库已有标签名称发送给你配置的 API 服务，可能产生该服务的费用。
- 草稿显示在页面中，可逐项修改。仅勾选的字段会填入表单；已有非空字段默认不勾选。
- 检查后点“填入选中字段”，再点“保存笔记”，概览随之更新。标签、摘要等也可完全手工填写。
- code/dataset 链接仅保留来源文本中明确出现的地址。未提供的链接不会自动搜索或编造。

## 从单文件版迁移

file:// 与 http://127.0.0.1:4174 属于不同存储位置。先在旧页面点“导出完整备份”，再在新页面点“导入备份”。导入会替换目标页面的文献库。以后固定使用同一个地址，避免混淆 localhost 与 127.0.0.1。

## 当前验证范围

使用模拟 API 响应验证读取、草稿解析、错误处理、链接校验和本地请求权限。尚未配置真实密钥，未进行真实模型生成验证。不同兼容服务的能力可能不同，以实际联调为准。
