# AI 整理提示词

`paper-summary.txt` 是实际发送给模型的 system prompt，控制一句话总结、标签、数据集、关键结果和结构化笔记的生成方式。

直接用文本编辑器修改并保存即可。服务每次生成时重新读取此文件，修改 Prompt 不需要重启；首次升级为此版本需要重启 start.cmd。

建议调整语言、篇幅、标签规则、笔记分段要求，但保留 JSON 输出要求和字段名，否则页面可能无法识别生成结果。

实际请求由两部分组成：

1. system：paper-summary.txt 的完整内容。
2. user：程序动态生成的 JSON，包含 `existing_tags`（当前文献库的标签名称）及 `source`（粘贴内容、读取到的 arXiv 标题/日期/摘要和论文网址）。拼接代码在根目录 server.mjs 的 generate 函数里。

图片不会进入此请求。网页和论文内容是待整理的数据，不是可以覆盖系统规则的指令。

新增字符串字段 `venue`：已核实的会议/期刊及年份，未知时为空。AI 预览支持勾选此字段，已有手动值默认不覆盖。发表来源与代码链接规则见 paper-summary.txt。
